# Programming-Java

Java coursework and programming exercises covering fundamental language concepts and problem solving.

[Repository](https://github.com/MirzaAlbab/Programming-Java)

## Features

- Primitive data types, conversions, and operators
- Conditionals, loops, recursion, and method overloading
- Arrays, sorting, matrices, strings, and console input

## Getting started

Install a JDK and open the exercises in a Java IDE.

```bash
git clone https://github.com/MirzaAlbab/Programming-Java.git
cd Programming-Java
```

Choose one exercise, inspect its `package` declaration and public class name, then place it in a matching package directory with a matching filename. Run that class's `main` method. For example, `1.TipeDataFundamental.java` declares `pkg1.tipe.data.fundamental.TipeDataFundamental`; import it into that package as `TipeDataFundamental.java` before compiling.

There is no root Maven or Gradle build; compiling every original filename in one command is not appropriate for this collection.

## Development and checks

Run individual exercises with representative console input and compare the output with the concept being studied.

## Project notes

Exercises are independent source files rather than a single application. Some filenames have numeric prefixes that differ from their public class names, and some files declare packages.
